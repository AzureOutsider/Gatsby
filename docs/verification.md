- 前端 89 项 Vitest 测试、4 项旧状态检查通过，包括已被 Git 跟踪的个人导出文件拦截与错误输出脱敏。
- Python 本地服务 5 项测试通过。
- TypeScript 和 Vite 构建通过，字体、图片及项目/第三方许可包含在发布目录。
- 词书检查通过：4 本登记、4 本种子；30 组核心文字与表面对比度最低 5.13:1。
- 新增个人导入内容与既有学习记录、调度、活动轮次在种子变更后保留的回归检查。

检查源码中的常见凭据和个人邮箱使用 `npm run check-public`；该命令不替代历史审计或资源授权确认。Git 历史清理在仓库外保存备份后完成，所有分支提交使用维护者的 GitHub noreply 邮箱。

## 已有功能覆盖

导入预览、UTF-8、CSV 多行引用和字幕格式、警告确认、存储失败保留输入、旧版数据迁移、拼错重练、翻卡队列、刷新续练、JSON 备份、首页选择、数据诊断及确认重置均有自动检查。

语音检查覆盖后台声音列表准备、主/备用各 2 秒启动预算、停止和切页取消、连续点击及旧回调隔离。测试使用模拟引擎，不证明真实设备的音质或网络延迟；需在实际浏览器中试听。

## 验证边界

本地运行记录使用 Windows、Node.js 22 和 Python 3.10。Linux 验证由 CI 执行；CI 配置存在不等于远程运行已经成功。核心色彩检查不代表完整 WCAG 认证。主要支持桌面浏览器，移动端与实际第三方托管服务须另行验收。
