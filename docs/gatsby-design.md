# Gatsby · 柔金夜宴

## 已确认的设计

- 名称 Gatsby，标识下方小字「你的英语学习室」。缩短文案、左对齐，与英文名称形成主次。
- Logo 与场景使用本项目原创 SVG：夜色、窗光与书页。`scripts/prepare_art.py` 可使用 Python 标准库重建 SVG 和 EXE 图标，无需个人原图。
- 英文 Nunito Variable（单层 g），本地打包；中文 Microsoft YaHei UI。学习单词 33–54px、例句 22px，说明与学习注释 18px，来源与辅助标签 14–16px，避免艺术字和细字体。
- 暖金与深棕打底，冷青与灰粉平衡。散景和颗粒静止，学习页降低装饰浓度，不做自动播放或漂浮动画。
- 桌面优先；照顾较窄桌面窗口，不开发移动端流程。

预演台选中的柔金夜宴：暖光60、冷光38、散景46、颗粒35、玻璃78、模糊18、侧光38。正式页用这套色彩关系与18px模糊；学习卡片提高底色不透明度，保证长时间阅读的对比度。不将设计试验滑块带入学习界面。正文和次级文字按 WCAG AA 复核，核心文字色与主要深色表面的对比度保持至少 4.5:1；说明文字最低使用 14px，学习语境使用 22px。

## 页面分工

顶部品牌 / 主导航 / 搜索与快捷键

今日学习：Logo 场景主视觉 + 今日复习目标 → 真实学习统计 → 收藏内容

内容库：连续输入搜索 + 分类 → 词书卡片 / 编辑 / 重置 / 删除

复习队列：轮次来源与数量 → 翻卡 → 可选拼写 → 完成记录

学习记录：统计 / 七日趋势 / 日目标 / 薄弱单元 / 轮次历史 / 数据备份

## 迁移约束

学习机制不随主题重置。不记得后持续展示答案、自动安排一次后续翻卡；记得后可下一张或再来一次。拼错加入队尾直到正确。所有正式轮次操作在持久化成功后才更新界面。

首次读取旧版数据时保存原始键快照 `gatsby-before-redesign-v1`。新状态写入 `gatsby-learning-state-v1`，旧键不覆盖，保留回退基础。继续支持 version 1 JSON 备份。空内容库不被种子词书重新填充。

默认服务固定 `http://127.0.0.1:8765`。数据属于浏览器及端口；占用时不偷偷换端口，避免看似数据丢失。
